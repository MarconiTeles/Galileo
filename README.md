# Galileo

Editor de vídeo vertical agêntico para macOS — corte por fala, timeline magnética,
legendas, multicam e b-roll, com um agente (Claude) montando a edição.

**[⬇️ Baixar a última versão](https://github.com/MarconiTeles/Galileo/releases/latest/download/Galileo.dmg)**
· macOS 14+ · Apple Silicon (M1 ou superior) · notarizado pela Apple

Este repositório hospeda **só a distribuição** (página de download + feed de
atualização do Sparkle). O código-fonte é privado.

- **Página de download:** https://marconiteles.github.io/Galileo/
- **Feed OTA (Sparkle):** https://marconiteles.github.io/Galileo/appcast.xml
- **Binários:** anexados em cada [Release](https://github.com/MarconiTeles/Galileo/releases).

As atualizações chegam sozinhas pelo app (Sparkle, EdDSA-assinadas) — o usuário
não precisa rebaixar nada.
